# Завдання 5. Міні-імпортер з теки

Стежить за `inbox/` (разом із підтеками) і переносить кожен `.csv` у `processed/` з датою в імені: `report.csv` → `report-YYYYMMDD.csv`.

```bash
dotnet run --project Task5
```

Увага: якщо файл змінюється багато разів, він обробляється один раз після 500 мс тиші. Заблокований файл пробується 3 рази, після чого помилка записується в `errors.log`.
