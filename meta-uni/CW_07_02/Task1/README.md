# Завдання 1. Нормалізатор текстових файлів

Рекурсивно копіює всі `.txt` з теки-джерела в теку призначення зі збереженням підтек: прибирає пробіли в кінці рядків, переносить рядки через `\n`, пише UTF-8 без BOM і формує `report.csv`.

```bash
dotnet run --project Task1
dotnet run --project Task1 -- Task1/samples /tmp/normalized --max-kb 1
```

Увага: файли більші за поріг (`--max-kb`, за замовчуванням 10 МБ) пропускаються з повідомленням.
