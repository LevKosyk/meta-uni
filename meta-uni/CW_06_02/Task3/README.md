# Завдання 3. Звільнення ресурсів

`TempFileWriter` пише рядки в тимчасовий файл, `AsyncFileCopier` асинхронно копіює файл із підтримкою скасування.

```bash
dotnet run --project Task3
```

Увага: `Dispose` можна викликати повторно, після нього запис кидає `ObjectDisposedException`. При скасуванні недописаний файл видаляється, а виняток передається далі через `throw;`.
